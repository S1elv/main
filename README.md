# Практическая работа № 4 — IaaS (учебная демонстрация в GitHub Codespaces)

> Важно: GitHub Codespaces — временная облачная среда разработки, а не полноценная виртуальная машина EC2 с постоянным публичным IP. Этот проект позволяет продемонстрировать Linux-терминал, запуск веб-сервера и публичный URL без банковской карты в пределах бесплатной квоты. Если преподаватель требует именно VM и публичный IP, согласуйте замену AWS EC2.

## 1. Запуск Codespace

1. Откройте репозиторий и выберите **Code → Codespaces → Create codespace on main**.
2. Дождитесь открытия VS Code в браузере.
3. Откройте **Terminal → New Terminal**.

## 2. Запуск веб-сервера

В Codespaces среда обычно основана на Debian/Ubuntu. Для демонстрации можно запустить Python HTTP-сервер без установки пакетов:

```bash
python3 --version
python3 -m http.server 8080 --bind 0.0.0.0
```

Оставьте терминал работающим. Откройте вкладку **Ports**, найдите порт 8080 и выберите **Port Visibility → Public**. Откройте Forwarded Address — должна появиться страница из `index.html`.

Если преподаватель требует именно Apache, проверьте наличие sudo и выполните в Codespace:

```bash
sudo apt-get update
sudo apt-get install apache2 -y
sudo systemctl start apache2
echo '<h1>Практическая работа № 4. IaaS</h1><p>ФИО: ВПИШИТЕ СВОЁ ФИО; группа: ВПИШИТЕ ГРУППУ.</p>' | sudo tee /var/www/html/index.html
```

Затем откройте порт 80 в **Ports**. Если установка Apache или systemd недоступны в текущем образе Codespaces, используйте Python-сервер на порту 8080.

## 3. Что сфотографировать для отчёта

- Скриншот 1: репозиторий с файлами проекта.
- Скриншот 2: терминал с запущенным сервером и строкой `Serving HTTP on 0.0.0.0 port 8080`.
- Скриншот 3: вкладка Ports с публичным forwarded URL.
- Скриншот 4: открытая страница сайта в браузере.

Не называйте forwarded URL «публичным IP EC2»: это адрес прокси GitHub Codespaces. В отчёте честно укажите, что AWS EC2 заменён учебной облачной средой по причине недоступности регистрации/оплаты.

## 4. Остановка

Нажмите Ctrl+C в терминале, чтобы остановить сервер. Остановите Codespace через меню GitHub Codespaces, чтобы не расходовать бесплатную квоту.

## Ограничения

- Codespaces предоставляет временную среду и forwarded URL; это не выделенная VM с постоянным публичным IPv4.
- Бесплатная квота ограничена правилами GitHub Free.
- Не храните секреты или пароли в репозитории.
